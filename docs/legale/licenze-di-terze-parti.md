# Licenze di terze parti

Frigolo è distribuito con licenza [AGPL-3.0](../../LICENSE). Insieme all'app vengono serviti anche
questi componenti di terze parti, ognuno con la sua licenza:

| Componente                                                                                          | Uso                       | Licenza                   |
| --------------------------------------------------------------------------------------------------- | ------------------------- | ------------------------- |
| [Lato](https://fonts.google.com/specimen/Lato)                                                      | carattere del testo       | SIL Open Font License 1.1 |
| [Playfair Display](https://fonts.google.com/specimen/Playfair+Display)                              | carattere dei titoli      | SIL Open Font License 1.1 |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (Copyright The JetBrains Mono Project Authors) | carattere dello scontrino | SIL Open Font License 1.1 |
| [uqr](https://github.com/unjs/uqr)                                                                  | codice QR dello scontrino | MIT                       |
| [Lucide](https://lucide.dev)                                                                        | icone                     | ISC                       |

Le altre dipendenze, con le loro licenze, sono elencate in `package.json` e nel file di blocco
`pnpm-lock.yaml`. I testi completi delle licenze dei caratteri si trovano nei pacchetti
`@fontsource/*` in `node_modules` e sul sito della SIL Open Font License.
